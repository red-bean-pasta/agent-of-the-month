# AI Assistant Memory System

This directory stores durable technical knowledge and interaction logs for agent tasks.

- `notebook/`: Durable technical findings, instruction design patterns, and architecture records.
  - `agent-instruction-design.md`: Insights into instruction authoring, probability calibration, and decisiveness.
- `historybook/`: Interaction history and task outcomes across turns.
  - `refactor_agent_rules.md`: Review and re-indexing of `AGENTS.md`.
